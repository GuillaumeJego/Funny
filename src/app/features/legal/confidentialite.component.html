Cette page explique quelles données Funny garde sur vous, pourquoi, combien de temps, et comment exercer vos droits. Le responsable du traitement est {{ legal.editeur }} ({{ legal.contact }}).

Les données que nous gardons

  • Votre compte : email, mot de passe (enregistré chiffré), pseudo.
  • Votre profil, si vous le remplissez : photo, bio, ville, genre, situation amoureuse, enfants, tabac, vapotage, alcool. Ces informations sont visibles par les autres membres connectés.
  • Votre date de naissance, si vous la donnez : elle n'est visible que par vous.
  • Votre activité : sorties créées, inscriptions, likes, amis, notifications.
  • Vos conversations : messages, photos et vidéos, lisibles seulement par les deux membres de la conversation.
  • La sécurité : membres que vous bloquez, signalements que vous envoyez ou qui vous concernent, suspensions éventuelles, date d'acceptation des conditions.
  • Les journaux techniques du serveur : adresse IP, date et type de requête, pour la sécurité du service.

Pourquoi

  • Faire fonctionner Funny : votre compte, les sorties, les amis et les messages.
  • Protéger les membres : traiter les signalements, suspendre un compte qui enfreint les règles.
  • Respecter la loi, par exemple répondre à une demande d'une autorité.

Les informations facultatives du profil ne sont traitées que parce que vous choisissez de les remplir ; vous pouvez les effacer à tout moment. Funny ne vend pas vos données, n'affiche pas de publicité et n'utilise aucun outil de mesure d'audience.

Combien de temps

  • Tant que votre compte existe.
  • Quand vous supprimez votre compte, tout est effacé immédiatement : profil, photos, sorties, inscriptions, amis, conversations, signalements et blocages.
  • Les journaux techniques : au plus un an, comme le prévoit la loi.

Qui peut les voir

  • Les autres membres connectés : votre profil public et vos sorties.
  • Les admins de Funny, pour la modération.
  • Les hébergeurs (voir les mentions légales), qui stockent les données sans les utiliser. Vercel, aux États-Unis, ne fournit que les pages du site et voit votre adresse IP ; ce transfert est encadré par le cadre de protection des données UE–États-Unis.
  • Le serveur de Funny est à Londres, au Royaume-Uni. L'Union européenne reconnaît que le Royaume-Uni protège les données personnelles de façon équivalente (décision d'adéquation), donc vos droits restent les mêmes.

Cookies

Funny n'utilise qu'un cookie de session, indispensable pour rester connecté. Il n'y a ni cookie publicitaire ni cookie de mesure d'audience, donc pas de bandeau à accepter.

Vos droits

Vous pouvez consulter, corriger, exporter ou effacer vos données, et vous opposer à leur utilisation. Le plus simple :

  • corriger : Mon profil ;
  • effacer : Mon profil → Supprimer mon compte ;
  • pour tout le reste : écrivez à {{ legal.contact }}. Nous répondons sous un mois.

Si vous pensez que vos droits ne sont pas respectés, vous pouvez adresser une réclamation à la CNIL (cnil.fr).

Âge minimum

Funny est réservé aux personnes de 18 ans ou plus.
